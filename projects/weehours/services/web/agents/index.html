AI agents

Connect your AI assistant

Wee Hours records facts. Your assistant interprets them: totals, patterns, a summary before the pediatrician visit, or "when should we expect the next feed?". It connects to your log over MCP (Model Context Protocol), an open standard supported by Claude, ChatGPT and many other tools.

Pick how to connect

Assistants that support sign-in (OAuth) need only the URL: you sign in with your Wee Hours account and approve access. For tools that don't, create a personal access token and paste it in.

  1. In Claude (web or desktop), open Settings → Connectors and choose Add custom connector.
  2. Name it Wee Hours and paste the server URL above.
  3. Choose Connect. Sign in with the account you use in the app, then choose Allow.
  4. In a chat, turn on the Wee Hours connector and ask something like “When did the baby last eat?”
  1. In ChatGPT, open Settings → Apps & Connectors. Custom connectors need Developer mode, under Advanced settings.
  2. Choose Create, name it Wee Hours, paste the server URL above and pick OAuth for authentication.
  3. Sign in with the account you use in the app, then choose Allow.
  4. Add the connector to a chat and ask away.

ChatGPT moves these menus around. If they've changed, look for “connectors” or “MCP” in its settings.

Create a token on your account page, then run:

claude mcp add --transport http wee-hours MCP_URL \
  --header "Authorization: Bearer wh_your_token"

Most clients (Cursor, Windsurf, VS Code, Zed and others) take a JSON entry like this one. Create a token on your account page and put it in place of wh_your_token.

{
  "mcpServers": {
    "wee-hours": {
      "url": "MCP_URL",
      "headers": { "Authorization": "Bearer wh_your_token" }
    }
  }
}

The transport is Streamable HTTP. Clients that support only stdio can connect through a bridge such as mcp-remote.

Read or write

A token is read-only unless you allow logging when you create it. A read-only assistant can answer questions but can't change the log. With write access it can also add entries, undo them and resolve duplicates, exactly as you could in the app. Every entry it makes is marked as coming from that assistant.

Assistants connected by sign-in get write access. You can disconnect them, or revoke a token, at any time on your account page or in the app under Settings → AI agents.

Things to ask

  • “How many wet diapers in the last 24 hours?”
  • “Make a table of feeds since Monday with total ml per day.”
  • “Summarize this week for our pediatrician visit tomorrow.”
  • “How long are her night stretches getting?”
  • “Log a bottle, 90 ml, at 4:15.” (needs write access)
Assistants can be wrong. Wee Hours gives your assistant accurate records, but what it concludes from them is up to the assistant, and it isn't medical advice. Talk to your pediatrician about anything that worries you.
