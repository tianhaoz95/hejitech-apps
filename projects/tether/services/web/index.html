Why Tether?

PRD v1.0 Architecture

Existing phone-as-Linux-desktop projects stack a Linux userspace, container, and X server on top of the OS. Tether takes the opposite approach: a rock-solid tiling window manager hosting three native tools—Web (WKWebView / Android WebView), SSH Terminal (SwiftTerm + Citadel / Termux + SSHJ), and Files (Local + SFTP)—with mandatory SHA-256 host key verification and hardware-backed Keychain/Keystore security.
