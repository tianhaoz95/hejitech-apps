Hardware Setup & Keyboard Shortcuts

Tether is built for USB-C DisplayPort Alt Mode external monitors (or Lightning-to-HDMI on older iPhones) paired with a Bluetooth or USB keyboard and mouse.

Terminal Shortcut Precedence (PRD §13.2)

When an SSH terminal tab is focused, Ctrl-C, Ctrl-D, Ctrl-Z, Ctrl-R, Ctrl-A, Ctrl-E, Ctrl-K, Ctrl-U, Ctrl-W, and Ctrl-L pass directly to the remote PTY (vim, tmux, shell).
