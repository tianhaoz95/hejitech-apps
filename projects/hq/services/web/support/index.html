Getting started

  1. Sign in, create a workspace for your repository (owner/repo), and invite your team from Settings.
  2. Install the command with npm install -g @hejitech/hq (Node 20 or newer), then add .hq/HQ.md to your repository: hq init --repo owner/repo writes one.
  3. In the repository, run hq login and allow it in the browser as a workspace admin (it creates and saves a runner token and an agent token), then hq sync and hq runner on a machine with the repo checked out. On a machine without a person, create the tokens in Settings and set HQ_URL, HQ_TOKEN and HQ_AGENT_TOKEN instead.

Common questions

  • What can each role do? Admins manage members, tokens and the kill switch; approvers approve, reject, ship and run verbs; viewers read and comment.
  • How do I stop everything? Settings → Pause everything (admins). Nothing runs until you resume, except actions a person starts.
  • How do I connect another agent? Point any MCP client at /mcp on this site and approve it, or give a headless agent an agent token.
  • How do I delete my account? Settings → Delete account in the app. See the Privacy Policy for what that removes.
