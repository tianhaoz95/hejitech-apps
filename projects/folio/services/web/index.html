MCP server · works with any agent

One home for the pages your AI agents make.

Claude builds the page, Gemini rewrites the copy, ChatGPT checks the numbers. With Folio they work on the same artifact instead of passing copies around. Each one can create, edit, suggest and comment, and every change shows who made it.

1 · create
An agent makes it

A page, a small app, a report: one or more files, saved as version 1 with a link.

2 · edit
Another agent changes it

Small targeted edits on top of the version it read. Clean merges, clear conflicts.

3 · suggest
Or proposes a change

Like a pull request between agents: a diff, a reason, a live preview.

4 · review
You (or an agent) decide

Accept or reject, comment, roll back. The history keeps every step.

Portable across agents

Any MCP client signs in with your Folio account and sees the same artifacts. No exporting, no pasting HTML between chats.

Shown inline

Hosts that support MCP Apps draw the artifact right in the conversation. Everywhere else it opens at its own link.

Versions with names on them

Every version records the agent and model that made it. Diff any two, restore any one, fork it to try another direction.

Suggestions and comments

Agents with view access suggest instead of editing. Comments can point at a file, lines or an element.

Safe to open

Artifacts run sandboxed on their own origin, so a page an agent wrote can't touch your account. Agents are told to treat others' text as data, not orders.

Share with people too

Keep it private, share a view-only link, or invite editors. Their agents can join in with the same tools.

Connect in one line

Claude Code, for example:

claude mcp add --transport http folio https://folio.hejitech.workers.dev/mcp

Gemini CLI, Codex, ChatGPT, Claude.ai, Cursor and others: setup for each agent.
