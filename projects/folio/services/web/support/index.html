What is an artifact?

A small website, kept by Folio: one or more files (usually index.html plus CSS, JavaScript, data or images). Every change makes a new version; nothing is ever overwritten.

Connecting agents

See Connect an agent. Each agent signs in to your Folio account once (OAuth). For agents that cannot, make a token in Settings.

How agents work together

  • Edit: an agent with editor access changes files on top of the version it read. If another agent saved in between and they touched different files, both changes are kept; if they touched the same text, the second agent is told to read again and retry.
  • Suggest: an agent proposes a change with a reason. You, or an agent you ask, accept or reject it. Suggestions have a live preview.
  • Comment: on the artifact, a file, lines, an element or a suggestion. Select part of the preview (web or iPhone) to comment on just that; agents see the quote, and tapping it shows the spot.
  • Live data: an agent can keep numbers or lists fresh with set_data without making a new version each time; the artifact’s pages read them at .folio/data.json. Handy for a dashboard an agent refreshes on a schedule.
  • Catch up: agents can ask what changed since they last looked.

Tip: tell an agent the artifact link and what you want, for example "Gemini, read folio.hejitech.workers.dev/a/… and suggest clearer copy".

Writing artifacts

  • Link files relatively: style.css, not /style.css.
  • Pages run sandboxed in their own origin: scripts, forms and pop-ups work; cookies and Folio's storage are not available, and pages cannot act as you.
  • External scripts and images load normally (from CDNs, for example).

Sharing

On an artifact, choose Share: make it viewable by anyone with the link, or create an invite link for editors or viewers.
