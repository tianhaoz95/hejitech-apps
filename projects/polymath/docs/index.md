# Polymath

Polymath transforms coding agents into interactive course authors. 

When you want to learn a complex topic (e.g. PyTorch for vLLM, SGLang, and TRT-LLM; LLM post-training infrastructure; or robotics octrees), Polymath provisions a managed directory, equips your agent with course-authoring skills and MCP preview tools, and compiles the result into an evergreen, interactive curriculum you can execute and practice at your own pace.
