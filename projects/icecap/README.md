# Icecap

Turn any Redfin, Zillow or Realtor.com listing into an investment analysis in seconds: a Chrome
extension with deal math in the side panel and cash flow on the map pins, a web dashboard for the
deals you save, and AI deal summaries that run on your own computer.

- **Try it:** https://icecap.hejitech.workers.dev · [Chrome Web Store](https://chromewebstore.google.com/detail/gbjiibgccfkpodffchmnokflclbnbfpl)
- **Docs:** https://tianhaoz95.github.io/hejitech-apps/icecap/ ([decisions](docs/decisions.md), [deployment](docs/DEPLOY.md))
- **Working on it:** [CLAUDE.md](CLAUDE.md) (layout, commands, rules)

Part of the HEJI monorepo: shared Supabase project (schema `icecap`), one Cloudflare Worker, Pro
through the shared HEJI Stripe account. Moved here from `tianhaoz95/icecap` (Firebase) in
November 2026.
